# MAcode
A web application for learning incidental vocabulary while watching bilingual subtitled videos.

Using the latest technology stacks, it can dynamically integrate newly encountered vocabulary into your customised vocabulary space. In particular, by offering AI-enhanced exercises, it could facilitate incidental vocabulary learning with expert vocabulary learning and enable your customised learner model up to date.

### Frontend
Vue.js 3.0

### Backend
Python, FastAPI, SQLAlchemy, alembic, PostgreSQL, Docker.
